# 📚 JavaScript Question Series

> A structured, topic-by-topic collection of JavaScript practice questions — from the absolute basics all the way to advanced concepts. Designed to sharpen problem-solving skills through hands-on coding.

## 🚀 About This Repo

This repository is a growing library of JavaScript coding questions organised by topic. Each question lives in its own dedicated `.js` file, named after the problem it covers, making it easy to navigate, practice, and track your progress.

Whether you are just starting out or brushing up on advanced patterns, there's something here for every level.

## 🛠️ How to Use

1. **Clone the repo**

   ```bash
   git clone https://github.com/GitEPatiL/Javascript-Question-Series.git
   cd Javascript-Question-Series
   ```

2. **Navigate to a topic folder**

   ```bash
   cd 10.loops
   ```

3. **Open any question file and write your solution**

   ```bash
   # Example
   code 01-print-numbers-1-to-10-using-for-loop.js
   ```

4. **Run your solution with Node.js**
   ```bash
   node 01-print-numbers-1-to-10-using-for-loop.js
   ```

## 💡 Question File Format

Every question file follows a consistent format:

```js
// Q1: Print numbers 1 through 10 using a `for` loop.

// Write your solution below:
function printNumbers() {
  // Your code here
}
```

The question is at the top as a comment, with a starter function stub below. Just fill in your solution!
